Bring your Codex sessions into Redcode. `redcode session import --from codex` reads the Codex CLI's local rollouts (`~/.codex/sessions` and `~/.codex/archived_sessions`, or the same folders under `$CODEX_HOME`) without changing them and imports a thread with its subagent threads, compactions, tool calls, images and token usage. Pass the Codex thread ID, `--latest` or `--pick`, as with the other sources. The import follows a thread across its continuation pages, groups each model response into one step, pairs every tool call with its result and marks calls that never finished as interrupted; messages other agents sent to a thread arrive as notes from that agent. Tool output is redacted for secrets and capped at 64 KB per call. Codex encrypts its reasoning and compaction summaries, so reasoning keeps its readable summaries and a compaction keeps the user messages Codex retained. Importing the same thread again reports it as already imported; a thread that continued since its last import comes in as a new copy. Developer instructions, injected environment context and file snapshots are not imported, and each import lists what it left out.
