Design audits now catch repetition and missed design-system reuse. Each direction gets a language-independent layout signature, so two variants that are the same composition are flagged, and a new design that re-creates an approved one (from any conversation in the same application) is named. The audit also flags components declared under a design-system component's name instead of imported, literal colors and fonts the design system's tokens do not declare, and reports how many design-system components the prototype imports. With dual reasoning one System One request, sent alongside the rest of the audit, confirms these findings or downgrades false positives to info; without an answer they stay marked unconfirmed. Every check now has a stable key: record a decision `accept:<key>` to keep a deliberate exception from being flagged again, and the report says which keys are still flagged since the previous audit. Gradient text and backdrop blur the design system declares itself are no longer called slop. The design-system block lists components per file with their import path instead of cutting off after 40 names, so a full shadcn ui folder (Dialog, Select, Table) stays visible.
