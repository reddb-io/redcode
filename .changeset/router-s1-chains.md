System One models served through chained routers (a RedRouter connected to another RedRouter, at any depth) are now recognised and labelled with their full route, for example `RedRouter → RedRouter → OpenCode Zen (via OpenCode Go) · JEV 1.13`. Each route is listed once, the router's recommendation first, and choosing one keeps the exact routed id the connected router expects. Chat model pickers name every router hop of a nested model and match it with the same model connected directly.
