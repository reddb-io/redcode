# Fix: envio de prompt falhando com "no schema with key or ref ..." (dialetos de JSON Schema de MCP)

## Bug relatado (o ponto)

```
failed to send prompt
unexpected server error
no schema with key or ref https://json-schema.org/draft/2020-1/schema. details in redcode.log
```

Quebra **todo prompt do projeto**: o erro é do Ajv (compilação do validador de `inputSchema` de tools externas/MCP), resolvido como ref não registrada. O ponto central deste plano: **corrigir esse bug na raiz** (strip de `$schema`/`$id` antes de `ajv.compile` no `external.ts` + pular tool não compilável) — a correção já implementada, embarcada e liberada via release.

## Objetivo

Restaurar o envio de prompts nos projetos do usuário: um `inputSchema` de tool publicado por servidor MCP que declara `$schema: https://json-schema.org/draft/2020-12/schema` (o default do zod v4; o erro do usuário mostra a variante `2020-1`) não pode falhar a compilação do validador e derrubar **todo prompt do projeto** com 500.

## Causa raiz (verificada no código)

- O erro é do **ajv**: "no schema with key or ref <uri>" acontece quando o schema carrega `$schema` apontando para um meta-schema que o build draft-07 do Ajv não registrou — ele tenta resolver a URI como ref.
- `packages/core/src/tool/external.ts` compila `inputSchema`s de tools externas (MCP) com ajv no `register`. Sem o strip, o compile lança e o erro estoura no envio do prompt (o 500 `unexpected server error` cuja causa real a transparência de erro agora exibe).
- O outro consumidor de ajv, `packages/core/src/util/json-schema-validate.ts`, **já** remove `$schema`/`$id` antes de compilar e falha aberto — sem problema.

## Situação: o fix já existe como WIP não commitado na árvore

O `git status` da sessão anterior mostrou trabalho em andamento de outra sessão, abordando **exatamente** este erro (não commitado):

- `packages/core/src/tool/external.ts` (modificado, +27/−10): remove `$schema`/`$id` antes de `ajv.compile` (comentário: "zod v4 emits `$schema: .../draft/2020-12/schema`") e **pula** a tool cujo schema ainda não compila (dangling `$ref`), com warning em vez de derrubar o registro.
- `packages/core/test/tool-external.test.ts` (novo, 3 casos): registro com schema draft 2020-12 + validação de argumentos (required) + skip de schema não compilável sem falhar o registro.
- `.changeset/mcp-tool-schema-2020-12.md`: changeset pronto descrevendo o fix.

O strip remove `$schema` **independente do valor** — cobre a variante `2020-1` do erro do usuário.
